Búsqueda de Raíces

En esta unidad exploraremos técnicas iterativas para encontrar los ceros de una función matemática $f(x) = 0$. Es decir, los puntos exactos donde la gráfica cruza el eje X.

Selecciona un método en el panel lateral para empezar a calcular.

Método de Bisección

Se programa una de las ecuaciones no lineales visto en clase. Se ingresa un valor inicial para poder calcular la solución de una ecuación no lineal y el programa presenta la solución, genera tabla de datos para revisar la solución.

$$c = \frac{a + b}{2} \quad \text{con } f(a) \cdot f(b) < 0$$

Método de Newton-Raphson

Se programa una de las ecuaciones no lineales visto en clase. Se ingresa un valor inicial para poder calcular la solución de la ecuación no lineal y el programa presenta la solución, se genera tabla de datos para revisar solución.

$$x_{k+1} = x_k - \frac{f(x_k)}{f'(x_k)}$$

Método de la Secante

Se programa una de las ecuaciones no lineales visto en clase. Se ingresan dos valores iniciales para poder calcular la solución de una ecuación no lineal y el programa presenta la solución, se genera tabla de datos para revisar solución.

$$x_{k+1} = x_k - \frac{f(x_k)(x_k - x_{k-1})}{f(x_k) - f(x_{k-1})}$$

Sistemas de Ecuaciones Lineales

Aquí resolveremos problemas estructurales del tipo Ax = b. Estas herramientas te permitirán encontrar el valor de múltiples incógnitas simultáneamente.

Gauss-Jordan

Un método directo. Transforma la matriz original en una matriz identidad para revelar la solución exacta del sistema de una sola vez.

$$[A \mid b] \xrightarrow{\text{operaciones elementales}} [I \mid x]$$

Jacobi

Un enfoque iterativo. Adivina una solución inicial y la pule ciclo tras ciclo usando las ecuaciones despejadas.

$$x_i^{(k+1)} = \frac{1}{a_{ii}} \left( b_i - \sum_{\substack{j=1 \\ j \neq i}}^{n} a_{ij} x_j^{(k)} \right)$$

Gauss-Seidel

La versión optimizada de Jacobi. Utiliza los valores recién calculados de inmediato, lo que acelera drásticamente la llegada a la respuesta final.

$$x_i^{(k+1)} = \frac{1}{a_{ii}} \left( b_i - \sum_{j=1}^{i-1} a_{ij} x_j^{(k+1)} - \sum_{j=i+1}^{n} a_{ij} x_j^{(k)} \right)$$

Factorización LU

Descomponer una matriz compleja en dos matrices triangulares (L y U) facilita enormemente la resolución de sistemas cuando solo cambia el vector de resultados.

Factorización LU (Doolittle)

El programa recibe un sistema de ecuaciones lineales, y el programa presenta la solución del sistema lineal de ecuaciones obtenida mediante el método de Doolittle.

$$A = L \cdot U \quad \text{con } l_{ii} = 1 \quad \Rightarrow \quad Ly = b, \; Ux = y$$

Factorización LU (Crout)

El programa recibe un sistema de ecuaciones lineales, y el programa presenta la solución del sistema lineal de ecuaciones obtenida mediante el método de Crout.

$$A = L \cdot U \quad \text{con } u_{ii} = 1 \quad \Rightarrow \quad Ly = b, \; Ux = y$$

Valores y Vectores Propios

Descubre las propiedades fundamentales de una matriz, esenciales para entender la estabilidad de sistemas, vibraciones mecánicas y algoritmos de búsqueda.

Método de la Potencia

El programa recibe una matriz cuadrada y el programa presenta el valor propio máximo y su vector propio correspondiente.

$$x^{(k+1)} = \frac{A x^{(k)}}{\|A x^{(k)}\|_\infty}, \quad \lambda_{\max} \approx \frac{(x^{(k)})^T A x^{(k)}}{(x^{(k)})^T x^{(k)}}$$

Potencia Inversa

El programa recibe una matriz cuadrada y el programa presenta el valor propio mínimo y su vector propio correspondiente.

$$x^{(k+1)} = \frac{A^{-1} x^{(k)}}{\|A^{-1} x^{(k)}\|_\infty}, \quad \lambda_{\min} = \frac{1}{\mu_{\max}}$$
